# VantaCart — Automated Global Dropshipping MVP

Independent Next.js demo project. No live payments, supplier purchases, supplier credentials, or ads are enabled.

## Run
npm install
npm run dev

## Build
npm run build

## Demo routes
- `/` storefront
- `/admin` operations dashboard
- `/products/orbit-magnetic-charger` product detail
- `POST /api/demo/order` simulated order endpoint

## Safety
`DEMO MODE` is hard-coded into the initial interface. Integrations are displayed as NOT CONNECTED.
